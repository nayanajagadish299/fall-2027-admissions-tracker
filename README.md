# Fall 2027 Admissions Dashboard — GitHub Pages

An interactive, static admissions dashboard and requirements matrix. Prepared 10 November 2026.

## Publish without coding
1. Sign in to GitHub, or create an account at https://github.com/signup.
2. Create a new **Public** repository named `fall-2027-admissions-tracker`.
3. In your repository, choose **Add file → Upload files**. Upload `index.html`, `requirements.html`, `.nojekyll`, and `README.md` **individually** (not the ZIP file). Commit to `main`.
4. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Select `main`, folder `/(root)`, then **Save**.
5. GitHub will show **Visit site** once published. The expected URL format is `https://YOUR_USERNAME.github.io/fall-2027-admissions-tracker/`; use the exact URL shown by GitHub, not a guessed link.

## Updating the website
Upload a revised `index.html` or `requirements.html` to the same repository with the same filename, commit the change, and GitHub Pages will redeploy. If GitHub is connected to ChatGPT, future revisions may be sent directly to the repository when supported and authorized. No automatic email syncing is built into this static page.

## Progress and privacy
Checklist and notes are stored in **browser-local storage** on the device you use. The website is public, but your local storage is not uploaded to GitHub. To move progress to a different browser/device, use **Export progress JSON** on the dashboard and then **Import saved progress JSON** on the other device. Keep exported JSON files private.

**Important:** This site is designed for a public repository. Do not commit transcripts, GPA documents, private admissions email threads, account credentials, passport information, personal contact details, recommendation letters, or exported progress JSON. GitHub Pages is publicly viewable.

## Files
- `index.html`: interactive dashboard
- `requirements.html`: detailed programme/deadline matrix
- `.nojekyll`: serve static HTML directly
- `README.md`: these setup instructions
